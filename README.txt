PUBLISH ON NETLIFY (MANUAL DEPLOY)
1. Go to https://app.netlify.com/drop in your browser.
2. Sign in or create a Netlify account if prompted.
3. Unzip keem-shot-it-website.zip on your computer.
4. Drag the extracted folder named "keem_shot_it_site" onto the Netlify Drop page (or select the folder if prompted).
5. Netlify will upload the site and provide a public preview URL.

BOOKING FORM NOTE
The form is configured for Netlify Forms. After deploying, open your Netlify site dashboard and check Forms/Form submissions. If form detection did not happen automatically, redeploy after enabling form detection or use Netlify's current form setup instructions. Test the form after publishing.
